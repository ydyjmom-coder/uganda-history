# 우간다 어린이 교육 선교 2027

2027년 우간다 주일학교·아동 교육 선교 전략 제안서와 1분 설명 영상입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 전략 제안 페이지. 상황 진단(탐색적 데이터 분석), 네 기둥(예배·성경캠프·성경교육·교사교육), 단기선교팀 연계, AI 교육 워크숍 차별화·타깃·포지셔닝·가격, 2027 로드맵과 마일스톤, 리스크, 5-Color 검토 |
| `uganda-mission-2027-1min.mp4` | 1분(61초) 설명 영상. 키네틱 타이포그래피와 라인 아트, 한국어 내레이션, 1920×1080 |
| `video.html` | 영상 원본. 브라우저에서 열어 미리 보고 MP4로 다시 저장할 수 있음 (Chrome 권장, `voice/` 폴더가 같은 위치에 있어야 함) |
| `voice/script_ko.txt` | 내레이션 대본 9줄 |
| `voice/make_voice_ko.ps1` | Windows 기본 음성(Microsoft Heami)으로 `k01.wav`~`k09.wav`를 만드는 스크립트 |

## 영상 다시 만들기

1. `voice/script_ko.txt`를 고친 뒤 PowerShell에서 실행합니다.
   ```powershell
   powershell -ExecutionPolicy Bypass -File voice\make_voice_ko.ps1
   ```
2. `video.html`을 로컬 웹 서버로 열고(`fetch`로 음성 파일을 읽기 때문) **MP4로 저장**을 누릅니다.

## 자료와 가정

인구·종교·접근성 수치는 공개 자료(UBOS, World Bank WDI, DataReportal, CIA World Factbook)의 근사치입니다. 가격, KPI, 캠프 규모, 우간다 학사일정은 제안을 위한 가정입니다. 외부에 공유하기 전에 최신 자료로 확인하세요.
